# Хозмаг — лендинг хозяйственного магазина

Однострочный лендинг (landing page) магазина хозяйственных товаров: инструменты, сантехника, бытовая химия. Целевое действие — заявка на «Сборку комплекта» через встроенную Яндекс Форму.

## Структура проекта

- `index.html` — весь сайт в одном файле: разметка, стили (`<style>`) и скрипты (`<script>`) инлайн. Внешних JS-файлов и сборки нет.
- `img/product-1…6.*` — фотографии товаров для витрины (webp/jpg). Хранятся локально.
- Референс дизайна: в корне проекта лежит скриншот референсного сайта (`mos-561943.oml.ru` — светлая база, карточки, голубые акценты).

## Запуск

Статический сайт — достаточно открыть `index.html` в браузере или поднять локальный сервер:

```bash
py -m http.server 8742 --bind 127.0.0.1
# → http://127.0.0.1:8742/index.html
```

> На этой машине `python` — сломанный алиас на Windows Store, используйте `py`.

## Технологии

- **Чистый HTML + CSS + vanilla JS**, без зависимостей и сборки.
- Шрифт **Manrope** с Google Fonts (единственный внешний ресурс помимо Яндекс Форм).
- Иконки — эмодзи + инлайн-SVG.

## Архитектура кода (index.html)

Секции страницы (в порядке следования, `id` для навигации):

| Секция | id | Назначение |
|---|---|---|
| Hero | `hero` | Оффер, CTA «Собрать мой комплект», коллаж из фото с параллаксом |
| Боли | `pains` | 3 карточки «Ситуация → Последствие» |
| Решение | `solution` | 3 строки «Мы делаем → Вы получаете» |
| Витрина | `products` | 6 товаров с ценами и кнопками «Заказать» |
| Оффер | `offer` | Скидка 15%, дедлайн, гарантия 24 ч, **Яндекс Форма** |
| Футер | `contacts` | Адрес, телефон, меню |

### Ключевые механизмы

- **CSS-переменные** в `:root` — цветовая палитра, радиусы, тени, градиент (`--grad`). Меняйте тему здесь.
- **Glassmorphism**: класс `.glass` (полупрозрачный фон + `backdrop-filter: blur`). Все карточки используют его.
- **Scroll-reveal**: класс `.reveal` + IntersectionObserver в скрипте. Задержка каскада через inline `style="--d:.15s"`.
- **Параллакс**: атрибут `data-para="0.06"` на блобах/карточках hero; скрипт на scroll + requestAnimationFrame выставляет CSS-переменную `--py`.
- **3D-tilt hero-коллажа**: mousemove на `#heroVisual`, вращает `.hv-inner` (только desktop, `min-width: 1021px`).
- **Модалка**: `#modal` + кнопки с классом `.js-open-modal`. Демо-режим — при submit просто показывает экран успеха, никуда не отправляет.

### Яндекс Форма (боевая)

В блоке `offer` внутри `.ya-form-card` встроена реальная форма:

```html
<script src="https://forms.yandex.ru/_static/embed.js"></script>
<iframe src="https://forms.yandex.ru/u/6afb127cb9e5ca882335b0e7?iframe=1" ...></iframe>
```

Заявки уходят в Яндекс Формы владельца. Заголовок над ней — `.ya-form-title` («Закажите себе сайт для бизнеса»). Не удалять `<script>` и не менять `name` iframe.

### Изображения

`.product-img img` использует `object-fit: cover` (фото — обычные снимки, не вырезки на белом). При замене фото сохраняйте пропорции примерно 1:1.

## Планы / известные ограничения

- Модалка и футер: телефон-плейсхолдеры `+7 (XXX) XXX-XX-XX` и город `[Ваш Город]` — заменить на боевые.
- Демо-форма в модалке не отправляет данные — при необходимости встроить туда ту же Яндекс Форму.
- Формулировки о скидке 15% и дедлайне «до четверга» захардкожены в тексте — обновлять вручную.
