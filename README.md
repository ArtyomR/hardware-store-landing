# 🧰 Хозмаг — лендинг магазина хозяйственных товаров

Современный одностраничный лендинг для продажи хозяйственных товаров: инструменты, сантехника, бытовая химия. Главный оффер — «Сборка комплекта» под задачу клиента со скидкой 15%.

## 🚀 Запуск

Сайт статический, сборка не нужна. Варианты:

**Вариант 1 — просто открыть файл**
```
Двойной клик по index.html
```

**Вариант 2 — локальный сервер (рекомендуется)**
```bash
py -m http.server 8742 --bind 127.0.0.1
```
Затем открыть: http://127.0.0.1:8742/index.html

> На Windows используйте `py` (алиас `python` может вести в Windows Store).

## 🖥 Структура страницы

1. **Hero** — заголовок, CTA «Собрать мой комплект и сэкономить», статистика (1500+ позиций, −30% бюджета, доставка 120 мин), живой коллаж из фото
2. **Боли** — три карточки «Ситуация → Последствие»
3. **Решение** — «Мы помогаем решать Ваши проблемы», три пары «делаем → получаете»
4. **Витрина** — топ-6 товаров с ценами
5. **Оффер** — скидка 15%, дедлайн «до четверга», гарантия замены за 24 часа, встроенная **Яндекс Форма**
6. **Футер** — адрес (ул. Складская, 4, парковка 15 мест), телефон, часы работы

## 🎨 Дизайн

- Светлая база с голубым градиентом и плавающими «блобами»
- Стеклянные карточки (glassmorphism, `backdrop-filter: blur`)
- Плавные анимации появления при скролле (IntersectionObserver)
- Параллакс фоновых элементов и hero-коллажа
- 3D-наклон hero-коллажа за курсором мыши
- Hover-анимации карточек и кнопок
- Шрифт **Manrope** (Google Fonts)
- Полный адаптив: планшет (≤1020px) и мобильный (≤660px)
- Поддержка `prefers-reduced-motion`

## 📝 Форма заявки

В блоке «Оффер» встроена Яндекс Форма (`forms.yandex.ru`) — заявки приходят её владельцу. Скрипт встраивания трогать не нужно.

Демо-форма в модальном окне (по кнопке «Собрать мой комплект») пока только показывает экран успеха — данные никуда не отправляются.
